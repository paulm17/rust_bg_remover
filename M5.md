# M5 — U2-Net family

M5 registers the five rembg U2-Net checkpoints at the pinned source revision
`030a9ed79dbfcf8c58a1dc15a8dca3ccd2355709`. The four single-mask checkpoints
(general, light, human and Silueta) use one `U2netSegmenter` adapter. It
reproduces `BaseSession.normalize`: RGB, 320×320 Pillow-LANCZOS-compatible
resize, global resized-image maximum with a `1e-6` guard, ImageNet
mean/std, NCHW, first output, safe per-image min/max, uint8 conversion and
LANCZOS restoration to the canonical source dimensions.

Cloth is intentionally separate. Its pinned contract is 768×768 and output
0 has four logits: background, upper, lower and full. Rust computes argmax
(first class wins ties), resizes the uint8 class-ID map, then applies category
equality, matching rembg's palette behavior. Cloth is excluded from general
scores and requires an explicit category in `m5-smoke`.

Weights remain external and ignored. Manifests pin URLs, source revision,
SHA-256, MIT licence evidence, tensor names/types/shapes and opset; missing
or tampered files fail closed before runtime initialization. The reported
SHA-256 values are the exact files published by the pinned rembg release
mirrors; availability is shown in `runs/m5-u2net/report.json`.

The hard-mask operation is explicit in `HardThresholdTransform`, configured
in the source uint8 range [0,255] and using strict `p > threshold`; equal
values are background. Constant and non-finite outputs are covered by unit
tests. Run the deterministic real-CPU report with:

```sh
ORT_DYLIB=/private/tmp/bgremove-m4-runtime/onnxruntime-osx-arm64-1.23.2/lib/libonnxruntime.1.23.2.dylib \
  cargo run -p bgremove-bench --offline --locked -- m5-smoke \
  --manifest models/m5_u2net.toml --input test_images/photoroom/1.png \
  --output runs/m5-u2net
```

Three small licensed level-2 parity fixtures (3×2, 2×3 and 5×3) are under
`tests/fixtures/m5`. They retain decoded RGB, complete preprocessed tensors,
raw U2-Net-P outputs, restored alpha and raw straight-alpha RGBA cutouts. The
Rust Pillow-compatible Lanczos path passes the full input tensor comparison at
max absolute error below 1e-6 for all three geometries. The pinned Python
3.12/Pillow 10.4.0/ONNX Runtime 1.23.2 CPU comparison, including raw output,
restored alpha and final cutout, is recorded in
`tests/fixtures/m5/python-ort-parity.json`.

Regenerate the tracked preprocessing fixture without redirecting stdout to the
file that the script writes (the script writes `parity.json` itself):

```sh
PYTHONPATH=/private/tmp/m5-py312-pinned \
  M5_RUST_ROOT="$PWD/tests/fixtures/m5/rust" \
  /opt/homebrew/bin/python3.12 tests/fixtures/m5/generate_rembg_u2net_fixture.py \
  >/private/tmp/m5-preprocessing-generation.log
```

Regenerate the pinned Python/ORT level-2 report and all domain artifacts with
the same explicit Python 3.12 environment:

```sh
PYTHONPATH=/private/tmp/m5-py312-pinned \
  M5_RUST_ROOT="$PWD/tests/fixtures/m5/rust" \
  M5_PARITY_REPORT="$PWD/tests/fixtures/m5/python-ort-parity.json" \
  /opt/homebrew/bin/python3.12 tests/fixtures/m5/generate_python_ort_parity.py \
  >/private/tmp/m5-python-ort-generation.log
```

Real inference is an opt-in gate requiring both `ORT_DYLIB` and an external
verified checkpoint, for example:

```sh
ORT_DYLIB=/path/to/libonnxruntime.dylib \
  cargo run -p bgremove-bench --offline --locked -- m5-smoke \
  --manifest models/m5_u2net.toml --input input.png --output /tmp/m5-u2net
```
