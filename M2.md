# M2 — decode, geometry, alpha and colour correctness

M2 keeps image decoding and PNG encoding in `bgremove-core::io` and restricts
the `image` crate to JPEG, PNG and WebP (`default-features = false`). EXIF
orientation is read from the decoder and applied once before the canonical grid
is recorded. A `CanonicalImage` always carries source alpha; opaque inputs
carry an explicit all-one mask.

Geometry is represented by an invertible `GeometryTransform`, including exact
f64 scale/offset, integer intermediate dimensions, and each integer
left/right/top/bottom pad or crop extent. Stretch maps pixel centres
independently in each axis.
Contain/thumbnail use a centered aspect-preserving scale and transparent/black
padding; cover/crop uses a centered aspect-preserving scale and crops the
excess. Pixel centres are represented as `index + 0.5`, and resampling samples
the corresponding zero-based coordinate. Borders clamp to the edge for
interpolation. Forward contain/thumbnail is explicitly resize-then-pad: target
indices outside the integer content rectangle are exact zero. Inverse
contain/thumbnail clamps every interpolation tap to that content rectangle,
never to predicted padding. Cover/crop returns zero for source centres outside
the visible crop while visible target-border taps use the declared edge clamp.
Odd excess is assigned asymmetrically with left/top=floor(excess/2) and
right/bottom=the remainder. Padded mask samples are zero, including source
pixels discarded by cover/crop. Thumbnail never upscales a source. Nearest, bilinear, triangle
(explicit tent kernel), bicubic (Catmull–Rom), and Lanczos3 are separate
selectable paths. Tests use non-constant asymmetric fixtures, exact nearest
membership, and an independent slow f64 reference implementation for all
non-nearest kernels at representative fractional coordinates and borders;
the production/reference tolerance is 1e-5 f32.

Masks and refined alpha are restored through the inverse transform. Source RGB
is never resized for final output. PNG outputs are straight-alpha RGBA at the
canonical source dimensions; RGB remains non-premultiplied, including when
alpha is zero. Alpha is quantized deterministically with round-to-nearest.

Transparent input policy is resolved explicitly in the M2 config itself:
`multiply-predicted` (the default, `A_final = A_predicted * A_source`) or
`replace-source-alpha` (`A_final = A_predicted`). Compositing helpers expose
encoded-sRGB and linear-light modes using the IEC sRGB transfer functions.

## Fixtures and gates

`tests/fixtures/assets/` contains tiny redistributable assets generated locally
from six asymmetric solid-color corner pixels: PNG, JPEG (quality 95), and
lossless WebP; a two-pixel transparent PNG; a GIF used only to prove the
default unsupported-format error; and a JPEG carrying a hand-authored minimal
EXIF TIFF Orientation=6 tag. Production decoder tests use these paths, assert
canonical dimensions/corners and source alpha, and reject GIF with an
actionable unsupported-format message.

```text
cargo fmt --all -- --check
cargo clippy --workspace --all-targets --offline --locked -- -D warnings
cargo test --workspace --offline --locked
cargo run -p bgremove-cli --bin bgremove -- run --input test_images/reference/1.png --output runs/m2-correctness
cargo run -p bgremove-cli --bin bgremove -- mask --input test_images/reference/1.png --output runs/m2-correctness
cargo run -p bgremove-bench -- run --input test_images/reference/1.png --output runs/m2-correctness-bench
```

Both CLI surfaces accept `--transparent-input-policy
multiply-predicted|replace-source-alpha`; metadata/config strings are derived
from that enum. The `run` command emits `cutout.png`, `resolved-config.json`,
and `run.json`; `mask` emits `mask.png` plus the same resolved configuration and
metadata. Repeated runs use the same codec settings, geometry, alpha policy and
metadata and therefore produce byte-identical outputs.

`runs/m2-correctness` is a tracked deterministic smoke artifact; M0 and M1
artifacts are not overwritten. M2 does not load models or create ONNX sessions;
those mechanisms begin in M3.
