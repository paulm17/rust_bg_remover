# M13 — Foreground-colour recovery

M13 adds four separable `ForegroundEstimator` candidates in
`bgremove-color`:

- `OriginalRgbEstimator` — the contaminated-RGB control;
- `MultilevelForegroundEstimator` — the PyMatting `_estimate_fb_ml`
  multilevel coupled F/B update with the pinned defaults;
- `FastForegroundEstimator` — two deterministic coarse/fine passes using the
  official PhotoRoom source contract: literal even kernel widths 90/6,
  one coarse iteration followed by one fine iteration by default, with both
  iteration counts explicitly configurable and safety-bounded,
  OpenCV reflect-101 borders, pass-1 blurred-B state, epsilon-protected
  divisions, and explicit encoded-sRGB/linear-light working spaces. A
  reference-size scaling mode and clamp-border policy are separate declared
  extensions, not source parity;
- `FbaForegroundEstimator` — consumes `RefinedMatte.foreground()` and fails
  clearly when the FBA channel is absent, rather than falling back to source
  RGB.

The pipeline now restores model-provided foreground/background RGB fields to
the canonical grid before invoking the colour estimator. A one-pixel M10
multilevel edge case was made safe by avoiding a zero `log2` level divisor.

Evidence:

- `tests/fixtures/m13/run_authoritative.py` executes the pinned PyMatting
  1.1.15 source twice and writes hashed reference F/B artifacts.
- `tests/fixtures/m13/reference/report.json` records source provenance and
  deterministic authority runs.
- `tests/fixtures/m13/run_fast_authority.py` source-executes an externally
  provisioned official PhotoRoom source snapshot at commit
  `a98fe5dfe4b61521de1a92dcaeb6d138f95bc97d` and pinned file hash, comparing
  both passes and returned blurred backgrounds across asymmetric geometries.
  The upstream repository has no checked-in license file, so the source is
  not redistributed in this repository; the fixture documents the exact
  clone/checkout/environment provisioning command.
- `runs/m13-foreground/report.json` ranks all five candidates on synthetic
  known F/B/A composites using visible edge-band foreground error and three
  backgrounds, including measured encoded-sRGB and linear-light candidates;
  alpha-zero RGB is excluded.
- Unit tests cover uniform, impulse, border, seeded-random and oversized box
  blurs against a slow reference, invalid/non-finite inputs, alpha extremes,
  deterministic runs, linear-light ablation, FBA presence/absence, and
  PyMatting source parity.

Because all candidates share the same known alpha, background changes
algebraically scale foreground error; the report states this metric limitation
explicitly. The synthetic report is a mechanism contract and recovery gate,
not a claim of PhotoRoom quality. Real FBA weights and PhotoRoom corpus
scoring remain external to this milestone.
