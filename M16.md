# M16 — Evidence-driven hybrid pipeline

M16 adds `bgremove-bench m16-smoke`, a deterministic P5 hybrid contract. The
contract fixture runs a general RGB-only segmenter once per image, computes
soft-alpha/gradient/contrast/topology risk, conditionally routes a
complementary RGB-only segmenter, builds an adaptive trimap, refines bounded
2x overlapping uncertain crops with weighted seam normalization, applies a
local alpha-weighted foreground recovery only in fractional-risk pixels, and
records an evidence-conditioned topology preservation decision. No prediction
function receives a filename, split, target, tag, or reference alpha.

Every component has a paired removal ablation under the single primary
PhotoRoomAgreement-v1 score with deterministic bootstrap CI,
tag aggregates, worst-decile evidence, measured warm wall-clock timing, and a
conservative modeled live-buffer bound. A component is enabled in the resolved default only
when its removal is beaten with a positive CI above the documented f32 noise
floor (1e-6). The current held-out contract qualifies all six components. This
is a synthetic mechanics result, not a promoted P5 claim. Intermediate route,
feature, crop input/output/weight, trimap, alpha, foreground, composite, diff,
metric, configuration, cache, and hash artifacts are emitted for every
evaluated synthetic pipeline/image bundle.

Scores use the M15 PhotoRoomAgreement-v1 contract: alpha/boundary/selection
terms plus windowed composite SSIM, with per-image and per-tag alpha, boundary,
gradient, fractional-alpha, composite and performance evidence. The current
contract report records positive paired CIs for all six components (router,
complementary model, adaptive trimap, crop refinement, selective foreground,
and conservative topology), so all six are enabled in the resolved synthetic
default. The synthetic oracle is explicitly separate from real claims and is an independent analytic
foreground/background/alpha construction; candidate functions are never used
to create references. The raw-mask probe uses exact RGB input hashes and each model's validated manifest
bytes, demonstrates six misses, forty-two downstream hits, corruption
detection, stale-key rejection, dimension rejection, and an on-disk fsync+
temp-file/rename round trip.

Four independent development fixtures with distinct geometry and color permutations
select the resolved mechanism policy; the six held-out validation fixtures only
confirm or fail that frozen policy. The crate-private M15 SSIM and
dimension-aware background helpers are shared by M16; this is the only M15
source change and preserves the frozen M15 report.

The checked-in six-image real arena and M15 report are consumed as provenance.
The current Edge ORT/runtime evidence lacks a compatible approved M16-owned
session, so the real path and blind promotion are fail-closed; the executor
preflight produces six explicit failure-zero fold rows and no synthetic score
is reported as a real champion. M15's blind lifecycle remains truthfully
`untouched`. A compatible official ORT plus verified M15 segmenter/cache/LOO
evidence is required before real P5 evaluation can activate.

## Reproduction

```text
ORT_DYLIB='/Applications/Microsoft Edge.app/Contents/Frameworks/Microsoft Edge Framework.framework/Versions/152.0.4191.66/Libraries/libonnxruntime.dylib' cargo run -p bgremove-bench --offline -- m16-smoke --output runs/m16-hybrid
ORT_DYLIB='/Applications/Microsoft Edge.app/Contents/Frameworks/Microsoft Edge Framework.framework/Versions/152.0.4191.66/Libraries/libonnxruntime.dylib' cargo run -p bgremove-bench --offline -- m16-smoke --output runs/m16-hybrid
```

The run compares two fresh complete synthetic quality trees (including HTML,
all ablation bundles, and manifest evidence). `artifacts.manifest.json` and
`artifacts.sha256` cover the deterministic quality scope; volatile
`performance.json`, report JSON/hash, and self-referential manifest files are
excluded. The exact on-disk manifest bytes are hashed, so the recorded fresh
and canonical quality hashes must match. No downloads occur.
