# M15 — Deterministic staged benchmark tournament

M15 adds `bgremove-bench m15-smoke`, a deterministic tournament engine over the
checked-in six-image arena (`test_images/arena.jsonl`). It never downloads
weights. The four approved external manifests (U2-Net, IS-Net, TRACER-B7 and
BiRefNet) are parsed and hash-verified before being reported as runtime-gated;
BRIA is explicitly not eligible because its checkpoint is absent and its
manifest is not approved. `P5-hybrid` remains reserved for M16.

The run exercises staged selection (raw segmenters, trimap/refiner, foreground
estimator), grid plus seeded random and Latin-hypercube sweeps, tune-only
selection, validation ranking, paired per-image deltas, deterministic 1,024
resample bootstrap intervals, track reporting, and the six-image arena rules.
The synthetic contract fixture supplies deterministic stage/metric tests and
performs six actual leave-one-image-out selections (five training images, one
held out). The real arena is inventoried and its six LOO folds are recorded as
not-run when the configured runtime cannot initialize an approved model; the
checked-in PhotoRoom inputs/references are not claimed unavailable. On a
compatible runtime, the real path overrides manifest split labels only for this
explicit fixed-arena protocol: each record is held out once, parameters are
selected on the other five, and only those six held-out scores enter ranking
and gate evidence. Once that real LOO consumes arena-5/6, their legacy
`blind` labels are recorded as overridden/retired and a new untouched blind
set is required before any promotion; until then the lifecycle remains
untouched. A separate larger-corpus blind split remains subject to the blind
lifecycle.

Raw masks are cached under `runs/m15-tournament/raw-cache` using
`sha256(input_rgb_sha256 || 0x00 || validated_model_manifest_sha256)`. Records include both
hashes, dimensions and finite f32 values. Cache reads fail closed on malformed,
stale or incompatible records; writes are fsynced to a temporary file and
renamed while a create-new lock prevents concurrent writers. The run also
performs deterministic corruption, stale-key and dimension-recovery probes.

## Reproduction

```text
cargo run -p bgremove-bench --offline -- m15-smoke --output runs/m15-tournament
cargo run -p bgremove-bench --offline -- m15-smoke --output runs/m15-tournament
sha256sum runs/m15-tournament/report.json
```

With no environment variable, the run is blocked before real inference. A
real-runtime probe was also run with the installed Edge ONNX Runtime dylib;
the adapters reached session creation but failed closed with exact unsupported
operator errors for U2-Net (`MaxPool(11)`), IS-Net (`MaxPool(12)`), TRACER
(`Selu(6)`), and BiRefNet (`ScatterND(16)`). BRIA remains unavailable because
its checkpoint is missing/unverified. Thus no real champion or real LOO
held-out score is promoted. `ORT_DYLIB=/path/to/libonnxruntime.dylib` enables
the same real six-image path on a compatible runtime. `artifacts.sha256`
records the deterministic hash of every generated artifact except raw caches.
The final Edge-ORT probe hashes are report
`ff83486f62d0d3660dc0b6e2909028a870671cb5b889398fdf698de851e4a576`;
artifact manifest
`35acfdef01ab9bb1af15ad382a4a3efa77d74204ab37b873ad3dd85a5983593c`.
The manifest contains 4,711 verified entries. Synthetic bundles use typed PNGs
(L8 alpha/trimap/diffs, RGB foreground/composites, RGBA cutouts) and include
per-bundle `hashes.json` coverage.
